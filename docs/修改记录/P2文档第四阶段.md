## 本轮实际完善内容

1. 先补复现测试，确认原 SDK 的默认 HTTP 层可在 408、503/Retry-After:0 或重定向时自行重放 Reply；另确认已中断线程仍可能发起 SDK 调用。修复后每轮 Reply 最多一次实际 POST。
2. 新增 LineMessagingTransport，复用已锁定 LINE SDK 10.2.0 的 MessagingApiClient、官方 JSON 转换器、Result Future 及异常适配。关闭连接恢复和 HTTP/HTTPS 重定向，正文标记 isOneShot，避免仅设置 retryOnConnectionFailure=false 仍发生 503 重放。保留原 SDK 超时和调度上限为具名常量，不加载报文日志。
3. Push 仍由原应用层对有限瞬时错误重试，并复用同一 Retry Key 与请求体；底层不叠加隐式重试。官方响应字段、业务序列化及 HTTP 错误码映射保留。
4. LineSendException 独立表达发送事实 NOT_SENT、REJECTED、UNKNOWN，保留既有 Reason 与状态码接口。SDK 前已截止/已中断/删除拒绝为 NOT_SENT；明确 4xx 为 REJECTED；已发起请求后的超时、断连、中断、5xx、重定向或无法解析的成功正文保守 UNKNOWN。
5. TurnReplyService 将已知未发起/明确拒绝收尾为 FAILED，不能把 NOT_SENT 伪装成 UNKNOWN；结果不确定仍 UNKNOWN，所有已准入成员正常消费，重投递不重新生成、不追加技术提示、不改 Push。Reply 的 409 不套用 Push 已接受冲突规则。
6. 先复现取消 Future 后删除屏障提前排空的问题，再增加 LineSendScope 与已有租约的 retain 能力：从已准入发送工作取得传输子租约，直到实际 callEnd/callFailed 才释放。删除期间的新工作仍拒绝，不能利用子租约新开独立任务；线程绑定在作用域结束时恢复。
7. 真实删除竞态暴露取消标记使 Redis owner 释放提前失败。新增单元复现后，在有界 owner 校验释放期间临时清除中断标记，最终恢复；不改为强制删除锁，不抢他人所有权，不因取消而假报清理完成。
8. 先复现技术提示冷却满表驱逐旧记录的问题，再改为保留未过期的已尝试/未知记录，容量不足保守抑制；普通重复不延后固定冷却，正常发送无法记入满表时使用单个有界全局抑制时间。默认 AI_TECHNICAL_REPLIES_ENABLED=false 不变，冷却清理仍接入既有 Purger。
9. 扩展既有失败/重试日志 detail.delivery_outcome 白名单，不新增数据库列或改变顶层 outcome 枚举；原错误正文、响应头和凭证仍禁记。
10. 新增真实 SDK/本地 HTTP 集成矩阵，覆盖 200、400/401/403/408/409/429、500/503、307、断连、超时后的迟到成功、非法成功正文、SENDING 新成员、缓存失败、取得发送权后删除、实际发送中删除及接受后删除。检查每个成员去重、原始数据、日志及凭证隔离。
11. DocumentedFlowIntegrationTest 使用同一生产传输策略，既有断言保留；新增完整虚构 UNKNOWN 入站、唯一出站尝试与安全失败事件，并在 ReplyOutcomeIntegrationTest 比对实际数据和重投递。
12. 接口文档更新至 1.5.7，实施计划、任务、总流程骨架、日志规范与示例步骤同步第四阶段事实。多成员权威历史及 MODEL 时机判断尚未实现，不写成已完成。

## 剩余限制与人工复核

1. 下一阶段为 V4 权威多成员关联、完整历史/缓存及事务验证；当前多成员过渡出站完整保留，但不进入下一轮上下文。MODEL 策略仍待第六阶段，完整关注/停机及负载仍待第七/八阶段。
2. NOT_SENT 只用于 SDK 前可确认没有发起调用的情况；已经发起的取消/超时不代表远端未执行、未接受或未收件。UNKNOWN 不自动补发，取消的本地传输子租约只是删除跟踪，不能撤回远端副作用；无法结束时删除按原超时明确失败。
3. 单进程去重有效范围内一轮最多一次发送；跨重启去重、可靠入站队列、端到端恰好一次及多实例协调没有实现。持久化仍尽力，不能根据无出站记录推断未发过。
4. 关闭底层重放/重定向可能让此前 SDK 自动恢复的网络故障显式失败；这是一次性 Reply 所需行为。Push 仍按原同 Key 有限重试；没有追加新费用限制或替换用户模型。
5. 请人工重启后使用虚构消息检查正常回复、连发接话时机和真实 Astra/max 延迟。技术兜底保持默认静默，无需手动清理数据或修改现有超时参数才能启用本轮修复。
